# Web Application Plan Format

Create one Markdown file per feature in this directory, using a short kebab-case filename such as `member-export.md`. Link the plan from the matching item in `../TODO.md`.

```markdown
# <Feature Name>

## Context
<Why this feature exists and the intended outcome.>

## Goal
<A concrete description of success.>

## Non-goals
<What is explicitly outside this work.>

## Phases

### Phase 1 - <name>
- [ ] Step
- [ ] Step

### Phase 2 - <name>
- [ ] Step

## Decisions
- **<topic>** (locked YYYY-MM-DD): <decision and rationale>

## Test Plan
<Commands and end-to-end behaviors used for verification.>

## Progress
- [ ] Phase 1 complete
- [ ] Phase 2 complete
- [ ] Tests pass
- [ ] TODO.md updated
- [ ] AGENTS.md Conventions updated (if applicable)
```
