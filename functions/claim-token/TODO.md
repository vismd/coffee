# Claim Token Function

## Purpose

This Appwrite Node.js function exchanges a short-lived claim identifier from the browser for an authenticated member identity. It validates and consumes the claim, reads or updates the associated member's Appwrite user mapping, and returns session or JWT information to the caller.

## Key Files

- `index.js` - request validation, claim consumption, identity linking, and response handling
- `package.json` - Node.js metadata, start command, and Appwrite SDK dependency
- `README.md` - required environment variables and deployment instructions
